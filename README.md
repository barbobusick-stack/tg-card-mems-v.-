## Описание проекта

Telegram-бот для коллекционирования карточек, написанный на Python с использованием библиотеки **aiogram 3**.

Бот позволяет пользователям получать случайные карточки раз в час, просматривать свою коллекцию и соревноваться с другими игроками в таблице лидеров.

Все данные хранятся в локальной базе данных SQLite (`db.db`).

### Возможности
- Получение случайной карточки раз в час (кулдаун 3600 сек.)
- Система редкостей: Common, Rare, Epic, Legendary
- Просмотр своей коллекции карточек с количеством каждой
- Таблица топ-10 игроков по очкам
- Автоматическое заполнение базы стартовыми карточками при первом запуске

## Структура проекта

```
project/
├── main.py       # Основной файл бота (хэндлеры, логика)
├── base.py       # Асинхронные функции для работы с базой данных
├── config.py     # Токен бота и настройки (создаётся вручную)
├── db.db         # База данных SQLite
├── requirements.txt  # Зависимости проекта
└── images/       # Изображения карточек
```

### Таблицы базы данных

| Таблица      | Назначение                                              |
|--------------|---------------------------------------------------------|
| `users`      | Данные пользователей (очки, время последнего получения) |
| `cards`      | Карточки (название, редкость, очки, вес выпадения)      |
| `user_cards` | Коллекция карточек каждого пользователя                 |

## Инструкция по запуску на Windows

### 1. Клонирование / копирование проекта

Если проект уже есть локально, этот шаг можно пропустить.

Если используете GitHub:
```bash
git clone https://github.com/your-username/your-repo
cd your-repo
```

### 2. Создание и активация виртуального окружения

```powershell
# Создать виртуальное окружение
python -m venv venv

# Активировать окружение
.\venv\Scripts\Activate.ps1
```

При успешной активации в начале строки PowerShell появится префикс `(venv)`.

> **Если PowerShell выдаёт ошибку выполнения скриптов**, выполните один раз:
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

### 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка токена

Создайте файл `config.py` в корне проекта:

```python
TOKEN = "ваш_токен_от_BotFather"
DB_PATH = "db.db"
COOLDOWN_SECONDS = 3600  # кулдаун в секундах
```

Токен можно получить у [@BotFather](https://t.me/BotFather) в Telegram.

### 5. Запуск бота

```bash
python main.py
```

Бот запустится в режиме long polling. Для остановки нажмите `Ctrl+C`.
